🛡️ MyClaude 六大工业级核心护城河

特性 1 五级容错代码替换 (edit_file)

不使用盲目的全量覆写，支持精确字符、换行符归一(CRLF/LF)、行尾空白忽略、缩进自适应对齐与 88% 模糊相似匹配，改代码极稳且省 Token。

myclaude/tools/editor.py

特性 2 双级上下文压缩 (Context Compactor)

软裁剪折叠早期庞大工具输出，硬压缩调用大模型提取阶段性三要素微摘要。彻底根治长任务爆窗与长指令稀释。

myclaude/core/context.py

特性 3 秒级原子快照与回滚 (/undo)

在磁盘物理写入前保留原始文件状态，支持一键原子级撤回并将还原事件注入 Agent 记忆，防止死循环撞墙。

myclaude/core/snapshot.py

特性 4 渐进式技能揭示 (Skills Engine)

系统提示词中仅常驻 <50 Token 的轻量 Catalog，需要时按需全量激活加载并配套执行专属脚本。

myclaude/core/skills.py

特性 5 MCP 协议与能力自进化 (FastMCP)

原生支持 Anthropic MCP 标准；Agent 能根据任务动态写出 Python FastMCP 脚本并在当前对话零重启热加载！

myclaude/mcp/ & tools/mcp_ops.py

特性 6 双轨伴生协同监控 (Sidecar IPC)

主终端与 sidecar.py 伴生窗口双轨并行，支持跨进程共享黑板状态订阅、实时战略下发与卡死任务紧急中断。

sidecar.py & core/state.py
